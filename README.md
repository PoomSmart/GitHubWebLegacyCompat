# GitHubWebLegacyCompat

### DEPRECATED: Recommend using [Reynard Browser](https://github.com/minh-ton/reynard-browser) to access GitHub website instead

---

A CydiaSubstrate tweak that injects compatibility styles (and a small amount of optional JS) on `github.com` for WebKit on **iOS &lt; 16.4**. It depends on **[com.ps.polyfills](https://github.com/PoomSmart/Polyfills)** for modern JavaScript and CSS features that GitHub’s own bundles rely on.

## What it does

### CSS (`styles/` → `layout/`)

GitHub’s Primer CSS uses `@layer`, `@container`, and `::backdrop`. Older WebKit ignores layered rules and can drop entire declarations when `::backdrop` appears in a selector list.

This tweak injects processed stylesheets at document end via `WKUserScript`:

| File | Role |
|------|------|
| `15.4-primer.css` | Core Primer; `@layer` / `@container` flattened, `::backdrop` rules stripped |
| `15.4-primer-react.css` | Primer React module CSS (same processing) |
| `15.4-issues-react.css` | Issues UI styles (injected only on `/issues` paths) |
| `15.4-issue-create-dialog.css` | Issue create dialog (issues paths only) |
| `15.4-layer-fix.css` | Regenerated by `update-scripts.js` to fix specificity after `@layer` removal on iOS &lt; 15.4 |
| `15.4-button.css` | Hand-maintained button fixes |

Reference: [Safari 15.4 release notes (`@layer`)](https://developer.apple.com/documentation/safari-release-notes/safari-15_4-release-notes#New-Features)

### JavaScript (`scripts/` → `layout/`)

| File | Role |
|------|------|
| `15.0-release-assets.js` | Small UX helper on release asset pages (optional) |

GitHub’s main application scripts are **not** bundled in this tweak anymore; **com.ps.polyfills** supplies APIs such as `requestIdleCallback`, RegExp lookbehind, and related compatibility shims.

Filenames use an iOS version prefix (e.g. `15.4-`): assets run only when the device version is **below** that prefix (`Tweak.x`).

## Building

```bash
npm install
node update-scripts.js    # optional: refresh Primer CSS + layer-fix from GitHub
make assets               # PostCSS + minify CSS; Babel + uglify JS → layout/
make package              # THEOS .deb (run make assets first)
```

Simulator inject (THEOS + simject):

```bash
make setup SIMULATOR=1
```

## Updating CSS from GitHub

```bash
npm run update-scripts
npm run update-scripts:dry-run
```

`update-scripts.js`:

1. Scrapes GitHub (issues + repo pages) for current CSS asset URLs
2. Downloads and processes **primer-css** and **primer-react-css** into `styles/15.4-primer.css` and `styles/15.4-primer-react.css`
3. Downloads **issues-react** module CSS when present in the scrape
4. Regenerates `styles/15.4-layer-fix.css` from primer-react + global nav CSS

It does **not** overwrite hand-maintained sheets: `15.4-button.css`, `15.4-issue-create-dialog.css`, or an existing `15.4-issues-react.css` if GitHub does not expose that URL in the scrape.

After updating, run `make assets` before packaging.

## Layout

```
Tweak.x              # Injection into MobileSafari / WebKit on github.com
scripts/             # Optional injected JS sources
styles/              # CSS sources (GitHub-derived + local fixes)
layout/.../GitHubWebLegacyCompat/   # Minified assets shipped in the .deb
update-scripts.js    # CSS download + processing automation
Makefile             # assets: js + css targets
```
